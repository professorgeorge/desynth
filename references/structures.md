# Structures to Avoid

Every pattern below is a structural cliché that signals AI-generated text. Learn to recognize them and replace them with direct prose.

## Binary Contrasts

These create false drama by negating one thing before asserting another. The negation adds nothing. State the point directly.

| Pattern | Problem |
|---------|---------|
| "Not because X. Because Y." | Telegraphed reversal |
| "[X] isn't the problem. [Y] is." | Formulaic reframe |
| "The answer isn't X. It's Y." | Predictable pivot |
| "It feels like X. It's actually Y." | Setup/reveal cliché |
| "The question isn't X. It's Y." | Rhetorical misdirection |
| "Not X. But Y." | Mechanical contrast |
| "stops being X and starts being Y" | False transformation arc |
| "doesn't mean X, but actually Y" | Negation-then-assertion crutch |
| "is about X but not Y" | False distinction |
| "not just X but also Y" | Additive hedge |
| "less about X and more about Y" | Soft binary disguise |

**Split-sentence form:** Where the negation and correction fall in two separate sentences ("The headline isn't the speed. The real story is Y."). Flag it the same way.  
**Multi-negation countdown:** "It's not the price. It's not the features. It's the trust." Cut straight to the positive claim.  
**Tailing negation:** Bare negation fragment tacked onto the end of a sentence — "The options come from the selected item, no guessing." Write the constraint as a real clause ("without forcing the user to guess") or cut it.

## Negative Listing

Listing what something is *not* before revealing what it *is*. Readers do not need the runway.

| Pattern | Problem |
|---------|---------|
| "Not a X... Not a Y... A Z." | Dramatic buildup through negation |
| "It wasn't X. It wasn't Y. It was Z." | Same structure, past tense |
| "Not this, not that, but rather..." | Extended striptease |

**Fix:** State Z directly. Skip the warm-up.

## Dramatic Fragmentation & Manufactured Punchlines

Sentence fragments engineered so every beat lands like a quotable closer: manufactured profundity.

| Pattern | Problem |
|---------|---------|
| "[Noun]. That's it. That's the [thing]." | Performative simplicity |
| "X. And Y. And Z." | Staccato drama |
| "This unlocks something. [Word]." | Artificial revelation |
| "One word: [word]." | Forced gravitas |
| "Two things happened. First..." | Countdown structure |
| "It had no preference for symmetry. No aesthetic prior." | Stacked drama fragments |

**Fix:** Complete sentences. Keep the one fragment that earns its emphasis and fold the rest into ordinary sentences.

## Rhetorical Setups & Stacked Questions

These announce insight or curiosity instead of delivering it.

| Pattern | Problem |
|---------|---------|
| "What if [reframe]?" | Socratic posturing |
| "Here's what I mean:" | Redundant preview |
| "Think about it:" | Condescending prompt |
| "And that's okay." | Unnecessary permission |
| "Consider this:" | Lecturer voice |
| "Imagine [scenario]." | Setup without payoff |
| "Let me explain." | The explanation should just start |
| "Ask yourself:" | Fake Socratic method |
| "Do I know how it works? Where it breaks? Which corners it cut?" | Stacked rhetorical questions |

**Fix:** Make the point. If you know the answer, say it. Convert stacked questions into the statements they hide.

## False Agency

Giving inanimate things human verbs to avoid naming the actor.

| Pattern | Problem |
|---------|---------|
| "a complaint becomes a fix" | Someone fixed it |
| "a bet lives or dies in days" | Someone killed the project or shipped it |
| "the decision emerges" | Someone decided |
| "the culture shifts" | People changed their behavior |
| "the conversation moves toward" | Someone steered it |
| "the data tells us" | Someone read it and drew a conclusion |
| "the market rewards" | Buyers pay for things |
| "the technology enables" | Engineers built something that lets people do X |
| "the system creates" | Someone designed the system to produce X |
| "the research suggests" | Researchers found X |

**Fix:** Name the human. "The team fixed it" beats "the complaint becomes a fix."

## Subjectless Fragments & Agentless Passives

Sentences with the subject dropped or the actor hidden: "No configuration file needed." "The results are preserved automatically." "Support for nested queries was added."

**Fix:** Name the actor when it clarifies — "You don't need a configuration file. The CLI preserves results automatically."

## Aphorism Formulas

Slot-fill profundity: "X is the language of Y," "X is the currency of Z," "the architecture of trust," "X becomes a trap," "X is not a tool but a mirror."

**Fix:** Replace the formula with the concrete claim it gestures at ("symmetric layouts feel more predictable to users" instead of "symmetry is the language of trust").

## Generic Future-Narrative Closers

Modal (may / could / will / is poised to) + "become" + (one of) the most [adjective] + (narrative / story / trend / theme / chapter / movement / force).

**Fix:** Pick the falsifiable prediction, or cut the closer entirely.

## Hedge-Stacked Predictions

Stacking a modal with a hedge adverb: "could potentially create," "may eventually unlock," "might ultimately transform."

**Fix:** Pick one. Say "could create" or "potentially creates."

## Real/Actual Adjective Inflation

Using `real` / `actual` / `genuine` / `true` as an empty intensifier on an abstract noun ("real on-chain tokenomics", "actual reward sustainability").

**Fix:** Unless explicitly contrasting with a named superficial version, drop the adjective and add the specific claim.

## Moral-Adjective Category Errors

Gluing moral/character adjectives (`honest`, `genuine`, `faithful`, `truthful`) onto non-agentic technical nouns (`shape`, `number`, `representation`, `curve`, `output`) or passive constructions ("flagged honestly").

**Fix:** State the concrete property instead ("a more realistic curve" instead of "an honest shape", "noted" instead of "flagged honestly").

## Invented Contrast-Pair Mirroring

One half is a real term of art, and the other is an invented counterpart for parallelism ("false precision rather than genuine accuracy").

**Fix:** Use an actual real opposite or state the positive claim directly.

## Narrated Candor & Self-Labeling Significance

Announcing disclosure or self-auditing significance: "Two caveats I would rather flag than let you discover later:", "That last move is the contrarian one."

**Fix:** Substance first. Cut the announcement framing.

## Bullet Lists of Bare Noun Phrases & List-Label Periods

5+ consecutive bullet items of short (≤6 word) adjective-plus-noun phrases without verbs ("Stable mining efficiency / Reliable pool connectivity"). Or terminating bold bullet labels with periods instead of colons (`- **Intros.**` instead of `- **Intros:**`).

**Fix:** Convert to prose paragraphs, write full claims with verbs, and use colons after labels.

## Wall-of-Text Replies & Recap-Flattery

Delivering reply-length comments (<150 words) as an unbroken multi-sentence block, or opening a reply by summarizing the maintainer's own work back at them with praise.

**Fix:** Break thoughts with whitespace, and lead with substance.

## Diff-Anchored Writing & Performed-Insight Phrases

Narrating code changes ("This function was added to replace...") instead of documenting current behavior, or using essayist tics ("sit with that for a moment", "that's not nothing", "X is dead; long live X").

**Fix:** Describe the current state directly and name the real magnitude.

## Negation Chains & Same-Opener Runs

Chains of "no X, no Y, no Z" or 3+ consecutive sentences opening on the same word ("Maybe nobody needed it. Maybe it solved...").

**Fix:** Say what the thing is and vary sentence openings.

## Stranded Auxiliary Contrast & Colon into a Triple

Landing reversals on a bare auxiliary ("The tool died; the data didn't.") or automatically padding lists to exactly three comma-separated items after a colon.

**Fix:** Write the contrast in full; audit the list to the real number of items.

## Structural Tests for Human Writing

- **Paragraph-reshuffle immunity:** If body paragraphs can be reordered without breaking the argument, the piece lacks a load-bearing through-line.
- **Treadmill effect:** If cutting 40–60% of a paragraph loses no information, it was restating the premise rather than advancing it.
- **Stylometric TTR (Type-Token Ratio):** For 200+ words, a TTR below 0.40 indicates vocabulary starvation. Broaden the concrete subjects.
